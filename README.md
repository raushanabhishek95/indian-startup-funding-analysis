## 📊 Project Overview

This project analyzes Indian startup funding data to uncover **funding trends, investor behavior, sector performance, geographic patterns, and startup-level insights**.

The dashboard is built from a practical **data analytics and business intelligence perspective** using Python, Pandas, Matplotlib, and Streamlit.

### Dashboard Views

- 📊 **Overall Market Analysis**
- 💰 **Investor Analysis**
- 🏢 **Startup Analysis**
